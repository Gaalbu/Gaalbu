### Sobre

Escrevo APIs que não desmoronam sob carga e interfaces que não parecem feitas às pressas. Fora do expediente, transformo problema do dia a dia em projeto: um app pra saber pra onde foi meu dinheiro, um jeito de mandar arquivo do celular pro Linux sem depender de nuvem. Gosto de terminar o que começo — a maioria dos repositórios abaixo tem testes, CI e um README que explica de verdade como rodar o projeto.

### Em destaque

| Projeto | O que é | Stack |
|---|---|---|
| **[Cadê Meu Dinheiro?](https://github.com/Gaalbu/cade-meu-dinheiro)** | Livro-caixa pessoal multiusuário: categorização automática, metas, orçamento e captura de gastos direto das notificações do Android via webhook. | TypeScript · Angular · Node |
| **[Supply Chain API](https://github.com/Gaalbu/Supply-chain-API)** | Rastreio de cadeia de fornecimento com eventos assíncronos, filas, notificações e trilha de auditoria. Monorepo com API e frontend. | Java · Spring Boot · Angular · RabbitMQ · PostgreSQL |
| **[LocalBridge](https://github.com/Gaalbu/LocalBridge)** | Transferência de arquivos P2P entre Android e Linux na rede local — sem nuvem, sem conta, sem custo. Descoberta automática via mDNS. | Flutter · Dart |
| **[ReceitasApi](https://github.com/Gaalbu/ReceitasApi)** | Gestão gastronômica fullstack com auth JWT, Angular SSR e cobertura de testes acima de 70%, com análise estática via SonarQube. | Java · Spring Boot · Angular · JWT |

Todos os outros repositórios são estudo aplicado: estruturas de dados, ciência de dados, algoritmos evolutivos e desafios de entrevista técnica — a lista completa está fixada no meu perfil.
